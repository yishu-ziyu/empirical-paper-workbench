# 项目方向

## 当前唯一目标

当前只关注华侨大学经济与金融学院本科毕业论文格式：

- 所属系统：`/Users/mahaoxuan/Desktop/经济学论文/实证论文项目模板`
- 当前模块定位：实证论文系统中的提交稿/初稿质量控制模板模块。
- 模块路径：`Manuscripts/templates/华侨大学本科论文LaTeX模板_2026-05-17`
- 上位规范：`00_原始材料/华侨大学本科毕业设计（论文）撰写要求及格式规范.pdf`
- 直接模板：`00_原始材料/经济与金融学院本科毕业论文格式模板.docx`
- LaTeX 入口：`02_latex模板/main.tex`
- 真实论文生成入口：`02_latex模板/scripts/build_paper_from_markdown.py`
- 当前校准产物：`04_编译输出/main_官方模板校准版.pdf`
- 当前真实论文构建产物：`02_latex模板/build/paper_v21_hqu/paper_v21_hqu.pdf`

旧的从论文正文初稿或范文中抽格式的结果只作为历史记录，不再作为当前验收标准。当前验收标准是：学校给的 PDF/Word 模板能否被 LaTeX 复刻出来。

这个模块不负责实证分析、数据清洗或论文内容生成；它负责最后交付层的格式质量控制：封面、诚信承诺书、摘要、目录、页眉页脚、图表三线表、公式编号、参考文献和最终 PDF 编译验收。

## 未来模板库方向

后续可以把这个项目扩展成网站或模板库，用来收集各高校、机关系统、单位文档规范，并生成对应 LaTeX 模板。

候选模板库字段：

- 机构名称
- 文档类型
- 原始材料路径或上传文件
- 上位规范 PDF
- 直接样式模板 Word
- 字体与字号规则
- 页面边距与页眉页脚规则
- 标题层级规则
- 图表公式规则
- 参考文献规则
- LaTeX 编译入口
- PDF 预览产物
- 对照检查状态

当前阶段不做网站，也不收集其它模板。先把华侨大学毕业论文格式做成一个可复用、可编译、可对照的单模板样本。
