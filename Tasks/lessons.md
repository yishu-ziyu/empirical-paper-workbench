# Lessons

## 2026-08-06：产品身份是全自动 Loop，不是门禁朝代

用户纠正：对齐 Discovery Loop 式连续实验环；仓库叙事必须以 **Continuous Empirical Loop** 为车标。  
审计 / claim / 质量门是 **环内刹车**。禁止用「半成品 + 红标 + 逐步 human signoff」当品牌。

应用：

- 只认 `docs/PRODUCT.md` + `README.md` + `SOUL.md`  
- 不复活 product-control / P0–P18 产品史诗  
- 红灯 → 自动纠正/回炉，不是「请确认第 N 步」终局  

## 2026-06-18：PDF 在盘 ≠ 课程论文就绪

`final_pdf_ready` 只表示文件写出成功。课程绿需要：结构、真实估计、表图、诚实方法边界、claim↔evidence、复现路径。

应用：

- 主路径走 `full_pipeline` / Agent harness，复用真实估计与证据脊柱  
- UI 可选；CLI 一等公民  

## 2026-08-06：书级 harness 是能力上限

`ai-agent-book`：Agent = Model + Harness；无评估则无进步；工具自包含完整回传；上下文按阶段切片；multi-agent 要有独立 IO。

应用：弱 Agent（只串脚本 + 人设）不算产品完成。
