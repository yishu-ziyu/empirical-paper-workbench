# 华侨大学毕业论文 LaTeX 模板任务计划

## 当前目标

只关注学校和学院提供的毕业论文格式材料，把华侨大学经济与金融学院本科毕业论文 Word/PDF 模板复刻为可编译、可维护的 LaTeX 模板。

旧的“从论文正文初稿/范文抽取格式”的测验性结果可以被当前官方模板覆盖；后续验收只看官方 PDF 与学院 Word 模板能否在 LaTeX 中复现。

## 任务判断

这不是“把 Word 文件直接转换成 LaTeX 文件”的任务，而是一个官方格式系统重建任务：

1. 学校 PDF 提供毕业论文格式规范的上位要求。
2. 学院 Word 模板提供封面、诚信承诺书、正文样式、页眉页脚、目录和图表样式的直接参照。
3. LaTeX 模板需要沉淀为可复用规则，而不是保留一次性 Pandoc 转换痕迹。
4. 正确路线是以官方材料为唯一当前参照，更新 `main.tex`，编译 PDF，并按 Word/PDF 逐页对照微调。

## 成功标准

- 能从学校 PDF 与学院 Word 模板整理出明确的格式规范记录。
- 能生成一个可用 `xelatex` 编译的华侨大学毕业论文 `main.tex`。
- PDF 输出覆盖封面、诚信承诺书、摘要、Abstract、目录、正文标题、图表、公式、参考文献、附录、致谢等关键页面。
- 当前模板稳定后，再决定是否拆成 `.cls` 或 `.sty`。
- 当前阶段不扩展到其它学校/机关模板；未来模板库方向另行记录。

## 当前不做的事

- 不直接相信 Pandoc 产物就是模板。
- 不一开始就写 `.cls`，避免过早封装错误规则。
- 不直接手工用空格、换行和硬编码间距模拟 Word。
- 不把正文初稿或旧范文当作当前验收标准；当前只验收学校 PDF 与学院 Word 模板。
- 暂不扩展到其它高校/机关模板，先把华侨大学毕业论文格式做稳。

## 目录说明

- `00_原始材料/`：学院 Word 模板、正文 Word、截图、参考 PDF。
- `01_格式规范/`：从 Word 反向整理出的格式规范表。
- `02_latex模板/`：`main.tex`、后续 `.cls` 或 `.sty`。
- `03_正文迁移/`：Pandoc 转出的原始 `.tex` 和人工清理后的章节文件。
- `04_编译输出/`：PDF、日志、辅助文件或预览图。
- `05_对照检查/`：Word 与 PDF 的页面对照记录。

## 等待用户提供的材料

当前学校 PDF 与学院 Word 模板已补齐。下一步不再等待材料，而是做逐页视觉对照和正式正文迁移。

## 后续产品方向

这个项目后续可能演进为一个网站/模板库：收集各高校、机关系统或其它机构的 Word/PDF 格式要求，抽取为结构化模板资料，并生成相应 LaTeX 模板。当前只做华侨大学经济与金融学院本科毕业论文格式，等单模板流程跑通后，再考虑模板库字段、上传入口、预览、编译服务和模板版本管理。
