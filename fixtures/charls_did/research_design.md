# 研究设计：CHARLS 城乡医保整合 DID

更新时间：2026-06-15

## 当前贡献句

本文使用 CHARLS 2011-2020 年面板, 检验城乡居民医保整合后新农合参保人与城镇职工/居民医保参保人的住院自付支出是否出现差分变化。当前证据不支持“整合稳健降低住院自付支出”的强结论；更准确的贡献是展示这一减负结论对固定效应、控制变量、聚类方式和安慰剂检验高度敏感, 并提示政策可能改变了医疗服务利用和支出结构。

## 研究问题

城乡居民基本医疗保险整合是否降低了农村中老年人的住院自付支出？

## 估计对象

当前版本估计的是：

```text
2018 年前后, 新农合参保人相对于城镇职工/居民医保参保人的住院自付支出变化。
```

这不是完整的省级政策 rollout 效应, 因为当前版本尚未接入各省实际整合时点和整合模式。

## 数据

- 数据源：CHARLS 2011、2013、2015、2018、2020。
- 样本：45 岁及以上, 持有新农合或城镇职工/居民医保的受访者。
- analysis-ready：80,375 个个体-年观测, 24,421 个个体。
- 主结果变量：`ln_oophos = log1p(oophos1y)`。

## 识别设计

- 处理组：新农合参保人。
- 对照组：城镇职工/居民医保参保人。
- 政策后：2018 年及以后。
- 主模型：个体固定效应 + 年份固定效应 + 人口、经济、健康控制变量。
- 标准误：基准为个体聚类, 稳健性报告个体 + 年份双向聚类。

## 当前实证结论

| 结果 | 解释 |
|---|---|
| M1/M2 显著为负 | 简单规格显示负向相关, 但受基线组间差异和共同趋势影响。 |
| M3-M5 不显著 | 加入年份固定效应后, 处理效应转为正且不显著。 |
| M5 `+0.081`, SE `0.053` | 首选规格不能证明住院自付支出下降。 |
| 双向聚类 M5 `p=0.6022` | 更保守推断下结果更弱。 |
| 2015 placebo 未通过 | 政策前结构性变化风险仍在。 |
| 住院总费用上升、门诊自付下降 | 可能存在利用和支出结构调整。 |

## 不能再写的结论

- 不能写“城乡医保整合显著降低农村中老年住院自付费用”。
- 不能把 M1 的 Oster 当作 M5 的稳健性证据；FE spec curve 已补齐，结论是 M5 周边规格方向为正但不显著。
- 不能把 2020 年事件研究下降直接解释为政策长期减负, 因为 2020 年受 COVID-19 冲击。
- 不能声称已经识别省级整合时点或整合模式效应。

## 下一步补强

1. 复查 Oster, 只在可对应 M5 口径时进入正文。
2. 补排除 2020 wave、level outcome、医疗负担比例、two-part / Heckman 或选择模型。
3. 若能获得省级整合时点, 将 treatment 从医保类型口径升级为地区-年份政策暴露口径。
