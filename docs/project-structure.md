# 项目主链路

`Data -> Program -> Results -> Manuscripts -> Submissions`

## 判断标准

- 数据有真源。
- 代码可重复运行。
- 结果可追溯到具体脚本。
- 手稿只从明确结果层取数。
- 投稿包是自包含材料。

## 新项目检查清单

1. 先建 `Data / Program / Results / Manuscripts / Submissions`。
2. `Data` 下分 `Raw / Interim / Final`。
3. `Program` 下分 `Clean / Analysis`，保留 `master.do`。
4. `Results` 下分 `tab / fig / temp`。
5. 正文只从 `Results` 或明确编辑层取数字。
6. 投稿前把材料整理到 `Submissions`。
7. 和 Agent 协作时，在 `Tasks` 记录当前阶段和边界。
