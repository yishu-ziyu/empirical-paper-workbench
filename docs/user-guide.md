# econpaper 用户手册

> 版本：0.1.0 | 更新时间：2026-07-31

## 产品简介

econpaper 是一款面向经济学研究者的 AI 论文协作工具。你上传真实数据集（CSV），通过对话式交互设定研究方向，工具自动生成完整的实证经济学论文，包含 LaTeX 源码、Word 文档和可复现的代码（Python / Stata / R / EViews）。

**核心特点**：

- **中文原生**：完整支持中文界面、中文论文生成、中文研究场景
- **章节式交互**：逐章生成，每章暂停让你审阅和调整
- **多格式导出**：LaTeX / PDF / Word 一键导出
- **代码可复现**：自动生成 Python / Stata / R / EViews 分析代码
- **HITL 评审**：AI 自动评审 + 人工决策，确保论文质量
- **CHARLS 原生支持**：自动检测 CHARLS 数据集，提供变量名映射向导

## 快速开始（5 分钟教程）

### 第一步：上传数据

1. 打开浏览器访问 `http://localhost:5173`
2. 点击上传区域，选择你的 CSV 文件
3. 系统自动解析数据集，显示列名、行数、数据类型和缺失值统计

**支持的格式**：CSV（最大 50MB）

### 第二步：设置研究方向

1. 在方向表单中输入：
   - **研究问题**：如"教育对收入的影响"
   - **因变量**：如"收入"
   - **自变量**：如"教育年限"
   - **控制变量**：如"年龄、性别、地区"
   - **计量方法**：如"OLS"、"DID"、"IV"、"RDD"
2. 系统自动生成 6 章大纲（引言、文献综述、数据描述、实证方法、实证结果、结论）
3. 你可以调整大纲后确认

### 第三步：逐章生成

1. 选择要生成的章节（如"引言"）
2. 系统基于你的数据和方向生成内容，实时流式推送
3. 生成完成后，系统自动评审，显示评分和反馈
4. 你可以选择：
   - **接受**：继续下一章
   - **拒绝**：让 AI 重写
   - **强制通过**：跳过评审继续

### 第四步：导出论文

全部 6 章完成后，你可以导出：
- **LaTeX 源码**（`.tex`）
- **PDF 文件**（需安装 latexmk）
- **Word 文档**（需安装 pandoc）
- **分析代码**（Python / Stata / R / EViews）

### 三栏布局

```
┌──────────────────┬──────────────────────┬──────────────────┐
│   左：大纲导航   │     中：编辑器       │   右：Agent 状态  │

│  ☑ 文献综述      │                      │  进度：3/6 章     │
│  ☐ 数据描述      │  教育作为人力资本     │  评分：0.85       │
│  ☐ 实证方法      │  的核心要素...       │                  │
│  ☐ 实证结果      │                      │  ┌────────────┐   │

│                  │                      │  └────────────┘   │
```

- **左栏**：大纲导航，显示 6 章完成状态，点击切换章节
- **中栏**：论文编辑器，流式显示生成内容，支持章节版本切换
- **右栏**：Agent 状态面板，显示生成进度、节点状态、评审信息，可折叠 EDA 侧边栏

### 数据上传与清洗

上传 CSV 后，系统自动执行 8 步数据清洗流程（每步完成后等待你确认）：

| 步骤 | 说明 | 交互点 |
|------|------|--------|
| 1. 数据契约与 profiling | 变量类型、缺失率、唯一值统计 | 查看 profiling 报告 |
| 2. 多期/多源数据合并 | 跨期数据合并 | 配置合并参数 |
| 3. 缺失值处理 | 缺失值检测与处理策略 | 选择处理方式 |
| 4. 异常值处理 | IQR 异常值检测与缩尾处理 | 确认缩尾参数 |
| 5. 变量重编码与构造 | 对数变换、独热编码、交互项等 | 配置变量构造 |
| 6. 样本筛选 | 按条件筛选样本 | 设置筛选条件 |
| 7. 面板平衡性检查 | 面板数据平衡性检测 | 查看平衡性报告 |
| 8. 清洗留痕 | 记录所有清洗步骤 | 查看清洗日志 |

### 研究设计

在方向设定表单中，你需要指定：

- **研究问题**：论文的核心问题
- **因变量 (DV)**：被解释变量
- **自变量 (IV)**：核心解释变量
- **控制变量**：其他控制变量
- **计量方法**：OLS / DID / IV / RDD / Probit / Logit 等
- **模板**：cn_journal（中文期刊）/ undergraduate（本科）/ master_thesis（硕士）/ english_submission（英文投稿）

### 章节生成与 HITL 评审

每章生成后，系统自动进行 5 维评审：

| 维度 | 说明 | 评分范围 |
|------|------|----------|
| 内生性 (endogeneity) | 内生性处理是否充分 | 0-1 |
| 识别策略 (identification) | 因果识别是否清晰 | 0-1 |
| 稳健性 (robustness) | 稳健性检验是否充分 | 0-1 |
| 贡献 (contribution) | 学术贡献是否明确 | 0-1 |
| 可读性 (readability) | 文字表达是否清晰 | 0-1 |

综合评分 ≥ 0.7 自动通过，否则需人工决策。

### 导出

支持四种导出格式：

| 格式 | 说明 | 依赖 |
|------|------|------|
| LaTeX (.tex) | 学术论文标准格式，含 4 套模板 | 无 |
| PDF (.pdf) | 编译后的 PDF 文档 | latexmk |
| Word (.docx) | 可编辑的 Word 文档 | pandoc |
| 分析代码 | Python / Stata / R / EViews | 无 |

**模板可选**：

- `cn_journal`：中文期刊模板
- `undergraduate`：本科论文模板
- `master_thesis`：硕士论文模板
- `english_submission`：英文投稿模板

## 常见问题 (FAQ)

### 数据相关

**Q：支持哪些数据格式？**
A：当前支持 CSV 格式。Excel、JSON、Parquet 格式支持在后续版本中添加。

**Q：数据会保存多久？**
A：当前版本数据存储在本地，重启后 session 数据会丢失（PostgreSQL 持久化正在实施中）。

**Q：CHARLS 数据集有什么特殊支持？**
A：系统自动检测 CHARLS 数据集（通过变量名模式匹配），提供向导将原始编码映射为可读变量名，支持选择 wave 和预设筛选条件。

### 论文生成

**Q：生成一篇论文需要多久？**
A：6 章完整生成约 10-30 分钟（取决于 LLM 响应速度和网络延迟）。

**Q：可以修改生成的内容吗？**
A：可以。每章生成后你可以审阅，不满意可以要求重写。章节内容还支持版本回滚。

**Q：支持哪些计量方法？**
A：当前支持 OLS、DID、IV、RDD、Probit、Logit 等。完整方法列表见 StatsPAI 项目文档。

### 技术问题

**Q：需要安装什么软件？**
A：详见 [部署文档](./deployment.md)。普通用户只需浏览器访问 Web 界面。

**Q：LLM 使用什么模型？**
A：当前默认使用 OpenAI GPT-4o-mini，可通过环境变量切换模型和提供商。

**Q：论文导出需要安装 LaTeX 吗？**
A：导出 LaTeX 源码不需要。导出 PDF 需要 latexmk，导出 Word 需要 pandoc。
