# 第一次自己走完：不满意的地方

日期：2026-08-18。
路径：CMUX 预览 `http://localhost:5173/` → 用示例数据 → 填 OLS（`y ~ age`，控制 `treat`）→ 看读数 → 点引言写出一章。
这是我当用户走完之后还别扭的地方，不是功能清单。

## 走完时实际看见什么

示例上传成功。
方向表只预填了一句「年龄和结果是否相关」，因变量、自变量、方法都是空的。
列名是 `id / year / y / treat / age`，表单旁边看不到。
点「看数据 → 描述统计」才出现列。
提交后约 20 秒出读数：`CLAIM association`，`STAR NONE`，表是 `| age | -0.0687 | 0.0083 | 0.0000 |`，`LIT crossref`。
点引言约 10 秒后出正文。
正文里 `## 研究背景` 的井号还在。
右侧评审立刻「自动不通过 · 0.43」，按内生性 / 识别策略打，要求 IV、RDD、双重差分。

## 最伤的

1. 示例走不通「示范」。
点「用示例数据」之后，人仍然要猜列名、猜方法。
课设样例应该带好：问题、`y`、`age`、OLS。
列名不该叫 `y`。

2. 相关分析被审成因果论文。
读数明明是 `association` / `NONE`。
评审却说没做 IV/RDD 就是严重缺陷。
第一篇样例一写完就是红灯，人会以为自己用错了产品。

3. 主表不像表。
一行管道符，没有「变量 / 系数 / SE / p」。
`STAR NONE`、`CLAIM association`、`LIT crossref` 是内部标签，不是给人看的。
文献只有一个词 `crossref`，点不开任何一篇。

4. 写出来的纸还是 Markdown 源码。
中栏自称是纸，人看见的是 `##` 和 `**粗体**`。
引言还带英文 `intro` 徽章。

## 台面乱

5. 顶栏挂着一整串 session UUID。
像调试台，不像写论文。
「econpaper v0」也像没做完。

6. 左栏同时摊着六章和 EDA 统计表。
点完「看数据」关不掉注意力。
章节是 `○ 引言 intro`，中英叠在一起。

7. 右栏八个「研究旅程」卡片加「可介入」。
交完方向、写出一章之后，这一列还在讲选题 / 文献 / 识别。
该看的评审被挤在下面。
八站不是人现在要做的三步。

8. 中栏还留着一句「先看见数字，再写正文」。
和已经改掉的进门文案同一路，装。

## 过程里没人陪着

9. 交方向要等十几秒，只有「正在确认方向并验真识别…」。
分不清是在估、在搜文献，还是卡死了。

10. 点一章立刻开写，误触就要再等一轮。
等的时候只有「在写…」，没有章名，也没有大概要多久。

11. 还没写出任何一章，「导出论文 / 导出代码」就能点。
空导出比灰掉更让人慌。

12. 默认模板是「中文核心期刊」。
示例走一遍就被写成贡献三条、结构预告，像在仿核心刊，不像课设第一刀。

## 识别说明帮不上忙

13. 「识别说明」里是「当前方法没有对应的识别诊断套餐」。
对。
但人需要听见的是：OLS 按相关写，这是正常的。
现在这句话藏在折叠里，评审却在正面骂你没做因果。

---

先改这三件，第一遍才像能用：
示例预填完整方向；
OLS 相关不要被打成识别失败；
主表和正文按人能读的样子出，不要管道符和 `##`。

这三件以及后续课设向打磨已做完。
开发停在 2026-08-18。
见 `docs/notes/devlog-2026-08-18.md`。
