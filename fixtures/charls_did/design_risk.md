# Design Risk Register

日期：2026-06-15

本文件是 `01 选题与研究设计` 的独立风险清单。它从 `research_design.md`、`causal_question.yaml` 和 `artifacts/empirical_strategy.md` 抽取，不改变当前论文结论。

## 当前设计一句话

本文用 CHARLS 2011-2020 年面板，比较 2018 年前后新农合参保人与城镇职工/居民医保参保人的住院自付支出差分变化。

当前估计对象是医保类型口径的 TWFE DID，不是省级 rollout ATT。

## 总体判断

| 项目 | 判断 |
|---|---|
| 可跑通 | 是 |
| 可写成技术样例 | 是 |
| 可强写“稳健减负” | 否 |
| 当前主结果 | M5 `treat_post = +0.081`, SE `0.053`, 不显著 |
| 当前合格表述 | 简单规格为负，但首选规格和保守推断不支持稳健平均减负；证据更像利用和支出结构调整 |

## 核心风险

| 风险 | 严重度 | 当前证据 | 处理方式 | 状态 |
|---|---:|---|---|---|
| 估计对象不是省级实际整合时点 | 高 | 当前没有 `first_treat_year`、省级整合时点或整合模式变量 | 正文明确不是 rollout ATT；后续建立政策 rollout 数据层 | 已暴露 |
| 处理组和对照组基线差异大 | 高 | 新农合与城镇医保人群在城乡、收入、教育、健康上不同 | 使用个体固定效应、年份固定效应和协变量；结论降级 | 已缓解，未消除 |
| 平行趋势支持弱 | 高 | 事件研究 2015 lead 不显著但只能弱支持；2015 placebo 未通过 | 不把 DID 写成强因果；在局限中报告 | 已暴露 |
| 主结果不显著且方向为正 | 高 | M5 `+0.081`, SE `0.053`；双向聚类 p 值更弱 | 主结论改为“不支持稳健减负” | 已处理 |
| 2020 wave 受 COVID 干扰 | 中 | 2020 是政策后期主要波次之一 | 已补排除 2020 稳健性；不能把 2020 下降直接写成政策长期效应 | 已处理 |
| 医疗利用变化会污染费用解释 | 中 | 文献和本项目结果均提示利用、总费用、自付费用可能同向或反向变化 | 同时报告总费用、门诊、住院、医疗负担比例和选择模型 | 已处理 |
| 选择进入正支出样本可能有偏 | 中 | Heckman-style 条件模型结果与平均效应不同，且缺强排除限制 | 作为扩展/局限，不改主结论 | 已暴露 |
| 方法文献要求更高 | 中 | Goodman-Bacon、Sun-Abraham、Callaway-Sant'Anna 等提示 TWFE 风险 | 当前版本只说明风险；若升级 rollout 数据层再上替代 DID | 部分处理 |

## 禁止写法

- 不能写“城乡医保整合显著降低农村中老年住院自付费用”。
- 不能把 M1/M2 的负向显著当成主结论。
- 不能把当前医保类型 DID 写成省级政策实施效应。
- 不能把 Heckman-style 条件样本负向结果写成平均财务保护效应。
