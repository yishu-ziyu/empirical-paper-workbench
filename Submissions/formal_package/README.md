# P5-B 正式论文包骨架

本目录是正式 paper package 的结构入口。本节点只创建目录和 manifest，不生成最终 PDF、docx 或正式正文。

- Source approval: `Results/json/formal_writeback_preflight.json`
- Package root: `Submissions/formal_package`
- Formal state write: `false`
- Final output write: `false`

## 目录

- `manuscript/`：章节扩写
- `literature/`：引用与文献
- `methods/`：方法叙述
- `results/`：结果表与样本说明
- `reproducibility/`：复现说明
