# Card (1993) 研究设计规范

## 1. 研究问题

附近是否有四年制大学（`nearc4`）作为教育年限（`educ`）的工具变量，能否得到比 OLS 更高的教育回报率估计？

## 2. 识别策略

### 2.1 核心识别假设

| 假设 | 内容 | 验证方式 |
|------|------|---------|
| 相关性 | `nearc4` 与 `educ` 相关（第一阶段显著） | First-stage F 统计量 |
| 排他性 | `nearc4` 只通过 `educ` 影响 `lwage` | 过度识别检验（若有多个工具变量） |
| 单调性 | 对所有个体，`nearc4` 对 `educ` 的影响方向一致 | 间接验证，无法直接检验 |

### 2.2 工具变量的经济学直觉

- 居住在四年制大学附近的青年，由于上学成本（交通、住宿）更低，更可能接受更多教育。
- 地理距离在个体层面是相对外生的（出生时的家庭选址决定）。
- 但需要注意：家庭选址可能与对未来教育的预期相关（能力偏差的另一种形式）。

## 3. 模型设定

### 3.1 OLS 基准

```
lwage = β0 + β1 * educ + β2 * exper + β3 * expersq + β4 * black + β5 * south + β6 * smsa + ε
```

预期：`β1(OLS) ≈ 0.073`，存在向上或向下的能力偏差。

### 3.2 IV (2SLS)

```
Stage 1: educ = π0 + π1 * nearc4 + π2 * exper + π3 * expersq + ... + v
Stage 2: lwage = β0 + β1 * educ_hat + β2 * exper + π3 * expersq + ... + ε
```

预期：`β1(IV) ≈ 0.133-0.145`，高于 OLS（暗示 OLS 存在向下偏差）。

### 3.3 控制变量说明

| 变量 | 含义 | 预期符号 |
|------|------|---------|
| `exper` | 工作经验（年） | + |
| `expersq` | 工作经验平方 | - |
| `black` | 是否为黑人 | - |
| `south` | 是否居住在南部 | - |
| `smsa` | 是否居住在 SMSA（标准大都市统计区） | + |

## 4. 诊断检验清单

### 4.1 第一阶段诊断

- [ ] `nearc4` 对 `educ` 的系数为正且显著
- [ ] First-stage F 统计量 > 10（Stock-Yogo 弱工具变量阈值）
- [ ] Kleibergen-Paap rk Wald F 统计量报告

### 4.2 第二阶段诊断

- [ ] `educ` 的 IV 系数与 OLS 系数比较
- [ ] Hausman 检验（OLS vs IV）
- [ ] Sargan/Hansen J 检验（过度识别，若有多工具变量）

### 4.3 稳健性

- [ ] 加入更多控制变量（`exper^2`, `smsa66`, 区域虚拟变量）
- [ ] 聚类标准误（按州或地理单元）
- [ ] 子样本分析（黑人 vs 非黑人）

## 5. 文献基准

| 来源 | OLS β_educ | IV β_educ | First-stage F |
|------|-----------|-----------|---------------|
| Card (1993) Table 2 | 0.073 | 0.133-0.145 | > 10 |
| Wooldridge (2013) | ~0.075 | ~0.132 | ~15 |
| Angrist & Krueger (1991) | - | 0.080-0.150 | - |

## 6. 实证 OS 执行路径

```
1. 确认变量角色 → outcome: lwage, treatment: educ, instrument: nearc4
2. 确认研究设计 → IV 识别策略
3. 生成 RunPlan → OLS + IV 两阶段
4. 执行 → StatsPAI sp.regress + sp.iv + sp.iv_diag
5. 结果审阅 → 对比 OLS/IV 系数、First-stage F
6. 草稿生成 → 基准结果表格
```
