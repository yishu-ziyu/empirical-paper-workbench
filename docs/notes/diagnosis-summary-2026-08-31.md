## 三、根因（更正后）

### 不是「定位漂移」

第一版采纳了「13 天定位三改（08-16 研究者级 → 08-18 课设 → 08-27 Apodex 自主）」的论断。
**复核后该论断不成立：**

| 被当作「定位变更」的 | 实际性质 | 证据 |
|---|---|---|
| 08-16 研究者级 | 架构决策，非定位 | ADR-0010，主题是「一个网页产品」 |
| 08-18 课设 | **devlog，非 ADR** | `devlog-2026-08-18.md:3-4`，无 Status 字段，未 supersede 任何东西 |
| 08-27 Apodex 式自主 | **文献检索源技术决策，与定位无关** | ADR-0011 全文检索「定位/自主/autonomous」**零命中** |

ADR-0011 的实际内容是：新增 `apodex.py` 作为文献检索旁路、默认链不变、过期即清理。
三个 agent 都因标题含 "Apodex" 而误读为产品定位转向。

### 真实的根因：一次干净的有意删除，被九天后的无意重建覆盖

先看证据再定性：

| 事实 | 含义 |
|---|---|
| 08-18 卸载是**干净且有意的**（import + JSX 双删，devlog:27 白纸黑字） | 用户做过正确判断，且执行到位 |
| 08-27 重建 `PAPER_NODES` 时，装回了**同一个被清空的右栏位置**，无人对照 08-18 记录 | 九天前的决策**失忆**了 |
| 1274 个测试全绿，含 11 个验证未挂载组件的测试 | 测试**保护**了残留，而不是暴露它 |
| 六处流程表述并存，无一声明所属层级 | 两层抽象（用户动作/引擎阶段）没有概念区分 |
| `bench.journey` 与 `guide.badge` 一字不差却是两个 key | 没有任何机制发现重复 |

**pm2 的定性（经 git 溯源证实，采纳）**：

> 漂移至少每次都是当下的决定；**失忆是教训执行过一次，然后被彻底遗忘。**

完整链条：

```
08-17  bc8c612  JourneyTimeline 挂载
08-18  20a3c57  课设定位 → 有意卸载（devlog:27「右栏不再摊八站旅程」）
08-27  e4484fb  PAPER_NODES 8 个英文节点装回同一右栏位置 ← 失忆点
08-27  0f1b382  bench.journey 4 步文案进中栏
08-29  9b00ca2  StepTimeline 取代 JourneyTimeline（后者成为永久孤儿）
```

**深层原因仍然是两层抽象没有概念区分**：
`bench.journey` 的 4 步（用户动作）与 ADR-0010 的 8 站（引擎阶段）本不冲突
（`agent/graph.py:3-8` 文档字符串证实：图只覆盖预写段，后续阶段由 Facade HITL 驱动）。
但重建时没有人知道「8 站是引擎层、右栏本来放的就是它、08-18 清空它是因为定位变了」——
因为**卸载的理由只写在 devlog 里，而 devlog 不是任何机制会去查的地方**。

**这一层在 AI 协作时代特别容易失守**：AI 会话能看到文件、能跑测试，**但看不到运行时，
也不会主动翻 13 天前的 devlog**。它看到 `JourneyTimeline.tsx` 存在、测试通过，就继续维护它。
测试越多，这个问题越隐蔽——1274 个绿灯里，有 11 个在为一个被有意卸载的组件站岗。

## 四、方案

### A. 确认 ADR-0010 是否仍然有效（0.5 天）

**这是唯一"现在不做就持续变贵"的动作，且只能奕枢拍。**

需要回答且只回答一个问题：

> **ADR-0010 的 8 站是否仍然有效？**

- **若有效** → UI 层必须收敛到它：删掉 #1/#2/#4 中多余的，把 #3 的英文标识符汉化，把 #5 接上
- **若要改** → 写 ADR-0012 **supersede** ADR-0010，然后按新 ADR 统一五套

**注意**：这个决策的性质不是「从三个定位里挑一个」，而是「**决定一份已经 Accepted 的决策要不要作废**」。
后者有明确流程（写 supersede ADR），前者没有。这个区别决定了它能不能真的收口。

顺带需要仲裁一组真实冲突：`agent/design/spec.py:86` 默认 `template: str = "cn_journal"`（期刊模板），
与 08-18 devlog 的「本科课程论文工作台，不是期刊投稿器」冲突。
但该 devlog 无 ADR 地位，所以**严格说 `cn_journal` 从未被正式作废**。

### B. UI 流程收敛（改 3-5 天，架构师原估 14.5 天）

架构师 14.5 天的估算基于「8 站 → 3 站」的**后端**改造。
更正后，**后端一行不用改**（它严格遵守 ADR-0010）。实际工作量在 UI 层：

- 删 `App.tsx:406-411`（静态 4 步）或删 `StepTimeline`，二选一
- `PaperPath` 的 8 个英文标识符汉化（`i18n.tsx:190-197`）
- 修 `paperPath.ts:95-96`：`translate_code` 与 `export_docx` 同源派生自 `canExport`，永远同步跳变
- 决定 `JourneyTimeline` 死链接上还是删除（删会触发 `make check-api-drift`，因为删路由会改 openapi.json）

**必须先做完 A**，否则是在给未定的决策做手术。

### C. 失效传播（8.5 天）

上游（换数据 / 改识别策略）变更后，下游估计结果、稳健性结果、正文章节不会失效。

唯一无论 A 怎么定都**无害**的动作，但**不解决根因**。
价值是"不把事情变糟"，不是"把事情变对"。

## 五、测试数的真相（避免误判）

架构师跑 **1274 passed**，lead 跑 **1062 passed**，差 216。
**不是代码回归，是环境差异。**

跑测试必须加 `--basetemp`，否则 pytest 的 tmpdir 与 WorkBuddy 沙箱 `sitecustomize.py` 冲突，产生 198 个假 error：

```bash
cd econpaper && backend/.venv/bin/python -m pytest -q --tb=line \
  -p no:cacheprovider --basetemp=/tmp/ep-pytest-<新目录>
```

三个硬 gate，缺一不可：
- pytest 必须 `--basetemp=<新目录>`
- 跑脚本必须 `PYTHONPATH=$(CURDIR):$(CURDIR)/backend`
- 导出类脚本必须 `DEBUG=true`（否则 JWT 校验 `sys.exit(1)`）

### 四条方法论教训

1. **讨论 UI 问题前先 grep 确认组件是否真的被挂载。** 三方都曾分析过未挂载的组件。
2. **`git show <commit>:<path>` 返回空 ≠ 文件里没有。** 必须先 `git ls-tree -r --name-only <commit>`
   确认路径在该 commit 存在，再取内容——否则「读不到」会被误判成「没有」
   （lead 第二版「从未挂载」错误即源于此，devlog:27 的原话当时就在那里等着被引用）。
3. **读 ADR 的 Status 字段，不要只看标题。** ADR-0011 标题含 "Apodex" 被三个 agent 误读为定位转向。
4. **区分「有 ADR」和「ADR 覆盖了这一层」。** 这个项目 ADR 文化健康，盲区在 UI 层——
   只看「有没有 ADR」会得出完全相反的结论。
