# 后续修订清单

更新时间：2026-05-17

## 对照基准

正式规范：

- `00_原始材料/华侨大学本科毕业设计（论文）撰写要求及格式规范.pdf`
- `00_原始材料/经济与金融学院本科毕业论文格式模板.docx`

参考视觉版：

- `00_原始材料/系统提交正本_工业机器人与劳动者重新配置_初稿.pdf`

说明：参考视觉版可以帮助判断页面密度、页眉、目录、摘要和正文观感，但它本身也有字体不统一、字号不统一等缺陷。后续修订不能盲目照搬，应以学校 PDF 和学院 Word 模板为硬性标准。

## 高优先级

### 1. 表格不要跨页

当前问题：

- Pandoc 生成的长表格默认使用 `longtable`，部分表格会跨页。
- 毕业论文视觉上更希望关键实证表格保持整体，不要被拆断。

后续处理方向：

- 对短表格使用普通 `table` + `tabular`，并加 `\caption`。
- 对关键实证表格启用不可分页环境，必要时缩小字号或横向压缩。
- 对确实太长的附录表格再保留 `longtable`。
- 在转换脚本中按表格类型区分“正文关键表”“附录长表”“图片组合表”。

验收标准：

- 正文关键表格不跨页。
- 附录长表如必须跨页，需要表头续接清楚。

### 2. 三线表格式优化

当前问题：

- 目前表格大多来自 Markdown 管道表，转换后虽然能编译，但三线表的列宽、对齐、表注、显著性星号和变量名展示还不够像正式论文。
- 日志中仍有若干 `Overfull hbox` 与表格对齐相关提示。

后续处理方向：

- 统一使用 `booktabs` 风格：`\toprule`、`\midrule`、`\bottomrule`。
- 表题放在表格上方，格式统一为 `表4-1 ...`。
- 表注独立放在表格下方，字号小于正文。
- 数值列右对齐或小数点对齐，文本列左对齐。
- 长变量名允许换行，但不能挤出页边距。
- 处理显著性星号、括号内标准误、样本量、固定效应和聚类标准误说明。

验收标准：

- 关键回归表视觉上接近正式经济学论文三线表。
- 编译日志中与表格相关的 overfull 提示明显减少。

### 3. 公式需要编号和标注

当前问题：

- Markdown 中的公式转换后能显示，但公式编号、公式说明和正文引用还不完整。
- 部分公式应使用 `equation` 或 `align`，而不是仅作为无编号展示公式。

后续处理方向：

- 为理论模型、基准回归、Bartik 工具变量、一阶段和二阶段模型加公式编号。
- 统一公式标注格式，例如 `(1)`、`(2)` 或按章节 `(4-1)`。
- 正文引用公式时使用 `式（4-1）` 这类格式。
- 多行模型使用 `align`，保证等号和变量解释对齐。
- 在公式后补齐变量含义说明，避免只给模型不解释。

验收标准：

- 重要公式均有编号。
- 正文能正确引用公式编号。
- 公式排版不溢出页边距。

## 中优先级

### 4. 页眉与页码对照

当前观察：

- 系统提交正本中页眉左侧为论文题目，右侧为 `华侨大学本科毕业论文`。
- 当前 LaTeX 版需要继续确认页眉内容、页码位置和前置页罗马数字/正文阿拉伯数字是否完全符合学校与学院要求。

后续处理方向：

- 对照正式模板确认页眉文字。
- 检查摘要、目录、正文、参考文献和附录的页码体系。

### 5. 摘要和目录页面密度

当前观察：

- 系统提交正本为 56 页，当前 LaTeX 版为 73 页。
- 页数差异主要可能来自行距、段距、表格跨页、图表占位和标题间距。

后续处理方向：

- 对照摘要页、目录页和正文第一页的页面密度。
- 优先从表格、图表、标题前后间距和列表间距压缩，不随意降低学校要求的正文字号和行距。

### 6. 字体统一性

当前观察：

- 用户指出系统提交正本本身也可能有字体不统一、字号不统一问题。
- 当前 LaTeX 版已使用 `Songti SC`、`Heiti SC` 和 `Times New Roman`，但斜体宋体会回退为正常宋体。

后续处理方向：

- 检查中文、英文、数字、变量名和参考文献的字体边界。
- 避免中英文混排造成局部字体跳变。

## 低优先级

### 7. 图题、表题语义化

当前问题：

- 部分图片来自 Markdown 的裸图语法，图题作为普通文本跟在图片后面。
- 部分图组来自 Markdown 表格，转换后更像图片表，而不是 LaTeX 原生图组。

后续处理方向：

- 将图片转换为 `figure` 环境。
- 将图组转换为 `subfigure` 或手工排布。
- 图题统一使用 `\caption`，并进入图目录或编号系统。

### 8. 参考文献格式

当前问题：

- 参考文献目前主要来自正文 Markdown 的文本列表。
- 后续需要确认是否必须严格 GB/T 7714。

后续处理方向：

- 若需要最终提交级规范，转为 BibTeX/BibLaTeX 或统一文本格式。
- 检查中文文献、英文文献、期刊、工作论文、数据来源的格式一致性。

## 当前不处理

- 不在本轮继续手工修 PDF 细节。
- 不直接修改论文研究内容。
- 不把系统提交正本当作唯一规范。
- 不扩展其它高校或机关模板；当前只固化华侨大学经济与金融学院本科论文流程。
