econpaper · 界面层重思 v2

这版不是换皮。先承认三条不能动的纪律（全部来自设计笔记），再给三个方向——它们回答的是同一个问题：整个界面的组织中心是什么。参考全部实名。

所有方向共享的纪律（写进笔记的，不再发明）

  • 色板锁死：paper #f4efe4 / ink #181515 / 绿 #2f6b4f 是唯一交互 accent / 红只给删除失败 / 金只给告警。design-sources.md · 本机货架
  • 身份色是语义层：选 2–3 个纸底上够稳的莫兰迪调，把「设定卡 ↔ 估计产物」同色绑定，悬停任一端另一端亮。RAG 轨迹卡拆解 §2
  • 动效纪律：≤200ms、ease-out、只动 transform/opacity、reduced-motion 全局坍缩、focus 环永不动画。DESIGN.md §10
  • 状态机语言：进行时动词（正在估计…），完成语报证据数（结论由 3 张表支撑）；未运行先展示 ghost 占位。RAG 拆解 §4/§5
  • 等待 = 阶段化反馈：凡 >2s 的操作必须显示所处阶段，禁止无阶段转圈。DESIGN.md §10
  • 先亮步骤和数字，再写正文；正文必须能点回来源；人随时能改方向。Notion Will's S：Show the work / Citations / Governors
  • 衬线给长读：论文正文永远衬线 70ch/1.8 行高；sans 管功能；mono 只管数字、变量、耗时。Notion Typography + 货架字体令
  • 门禁 = 显式解锁条件：禁用按钮必须说明怎么解锁。DESIGN.md §10
方向 A 稿纸即产品 聊天退位，论文纸面升为界面中心

回应《The Conversation Trap》的批评：研究的产出物是论文，不是对话流。空桌就是一张白纸加一行写线（入口仍是你定稿的输入卡）；进入工作台后，中央永远是那张正在生长的稿纸——正文里的系数、变量、引用全部是活的：系数悬停亮出回归表对应行与设定卡（身份色绑定），论断尾注点开侧栏来源卡。工具全部藏进纸边。
