# 展示与首次体验 · 设计审阅稿

状态：待用户确认；未实施产品页面、未公开部署、未开展真人试用。

econpaper 面向正在学习或开展实证研究、需要核对分析设定与结论依据的学生和研究者。先用 Card 1995 教学案例说明：同一数据的两条估计为什么不同、数字来自哪里、哪些结论还不能下，再进入现有桌面研究工作台。当前最完整的验证范围是 Card 案例；不承诺任意用户数据完整成文、全部方法的工作台体验、跨语言数值复现或生产服务质量。

## 可审阅产物

- [完整页面设计](index.html)：整页 / 分节查看，中文 / English 分开，宽屏 / 手机审阅。无 API、无外部字体、无模拟运行计时。手机只展示；研究入口展示桌面交接说明。
- [证据与能力映射](evidence.md)、[去敏真实结果对](card-pair.json)。没有复制数据集和大日志。
- [80 秒演示分镜](storyboard.md)、[真人试用任务与空白记录](user-study.md)。

直接打开本目录的 [index.html](index.html)，即可完整离线审阅，无需启动服务或占用端口。推荐 1440×900 与 390×844；页顶「全部」可看完整顺序，「01–03」可逐节审阅，不缩成一张长图。审阅控件属于设计工具，实施时不进入产品。页面内入口仅弹出拟接现有工作台的说明，不创建研究。

## 完整结构与入口行为

1. 价值与入口：一句任务价值、明确受众、两真实结果的轻量预览；主入口「看真实案例」，次入口「进入桌面工作台」。不先索取数据或逼注册。手机改为「了解桌面研究入口」。
2. 真实案例：先并排比较 OLS/IV，再展开改变与保持的设定，再查数据与计算来源，最后显示不能作出的结论。结果身份始终 A/B，颜色和文字共同标识，键盘焦点同样可见。来源使用原始字段与两个公式，既可读也可核验。无推算的百分比和置信区间。案例是历史记录重排展示，不是现有 UI 截图或现场执行。
3. 当前能力与限制：Card 范围、用户数据范围、论文与导出边界各自配对。对外直述自带数据全过程和完整成文质量尚未验证、下载脚本不保证跨语言数值一致；归档结果章的降级 mock 事实保留在 evidence.md 与 HTML 审阅注释，不作为真实 LLM 成文证据。完整末尾入口接现有桌面工作台。页尾不放用户评价、速度或方法数。

GuidePage 的 onTrySample 对应旧课设样例，不作为 Card 入口。拟实施由现有空桌 DeskPage.onTryCard 触发 Card，onPickData 保留自有数据入口；本轮不动。主入口先读案例，最终入口进入现有空桌，再由用户主动选择 Card；不会自动替换已有会话，也不会让宣传页阻拦已有会话恢复。正式接线须在下一轮确认当前 App 路由与已有会话行为，不能用本设计稿证明已接通。失败、加载、登录要求沿用现有业务状态并单独验收，不以动画替代执行。

## 双语与响应式

系统文案完整单语，变量、OLS/IV、Card 专名保留。切换只影响展示语言；不暗示改变论文正文语言。宽屏最大内容宽度 1120，案例两栏；小屏单列，结果 A/B 保持邻接，来源长 hash 与公式自动换行。触控目标至少 44px，原生 details 可键盘操作，无自动播放或必需动效。纸底 #f4efe4、墨 #181515、唯一交互绿 #2f6b4f；本地衬线回退给标题，sans 给 UI，mono 给数值。专业克制视觉沿用 design-sources 和现有工作台。

设计来源：完整 GuidePage/DeskPage（现有入口和状态），docs/specs/design-sources.md（墨纸绿）；living/INDEX.md 与 pageflow/index.html（把研究内容作为视觉主体，控件从简）；Notion Show the work（主 agent 本轮读取：数字与来源先于正文，用户决定下一步）。不搬外部动效或新增库。
