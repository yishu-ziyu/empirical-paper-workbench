econpaper · 界面层设计重思

先看现状体检（为什么必须重想），再看三个完整方向。每个方向都画了空桌和工作台两个核心界面，配设计原则与 token 表。

现状体检：问题不是某一页丑，是没有「一个」界面层

以下每条都是今天在代码里核对过的事实，不是感觉。

  1. 三套视觉语言并存：空桌是白色聊天工具（#fffefb 气泡流），工作台是奶油纸学术风（#f4efe4 衬线），落地页是墨色海报——用户每前进一步就换一次产品。DeskPage / ThreeColumn / GuidePage
  2. 控件没有规则：同样是一颗按钮，圆角有 rounded-full / rounded-md / rounded 三种，字号有 11–13.5px 五档，同一屏混用。App header / DeskPage 输入区
  3. 字体角色失序：mono 被用在 eyebrow、运行记录、正文标注；衬线被用在问候、章节标题、纸面正文；正文 12–15px 无字阶——想表达「纸感」的元素和「仪表」的元素互相渗透。全局
  4. 两个三栏、语义不同：空桌的 ResizableWorkspace 三栏（会话/对话/进度）和工作台的 ThreeColumn 三栏（章节/论文/证据）结构相似但骨架不连续，切换时空间感断裂。
  5. 弹窗各自为政：导出、评审门、代码导出各写一套遮罩、圆角与按钮排布。DocExportDialog / ReviewGateDialog / CodeExportDialog
  6. 文案口径曾各自为政：econpaper Computer / Research Computer / 估计门 / Write Queue——今天已统一成「研究进度」口径，但这类问题说明缺一份全产品共享的界面语言规范。
方向一 一张纸 · 素雅学术 整台产品就是一张纸，工具退到边上来

把已定稿的「纸上扉页」贯穿到底：所有界面共享纸底、发丝线、衬线标题。对话不是气泡，是纸上的批注；进度不是仪表盘，是目录。品牌感最强，和落地页、论文纸面天然同源。

  • 纸底只有一个：全产品 #f4efe4，卡片即纸片 #fffdf7
  • 发丝线 1px 分隔，不做阴影和浮层卡片
  • 衬线只给「纸的成分」：标题、问候、论文正文
  • mono 只给数字、代码、变量名
  • 圆角统一 3px，圆角即印刷，不做胶囊
纸底 纸片 墨 墨绿 发丝线 衬线 = 纸 · 无衬线 = 功能 · mono = 数字

方向二 安静的工具 · 中性高效 产品是仪器，纸只是产出物

全产品换上中性的工作台外壳：恒定的左侧窄导航 + 面板 + 列表，密度优先、装饰归零。衬线只允许出现在论文纸面正文里——纸是产品产出的东西，不是产品的皮肤。会话跨界面连续，像 Linear 一样「在哪都能接着干」。

  • 恒定壳：窄导航（会话/论文/数据/设置）永不消失
  • 白底 + #e8e6e1 一档边线，状态只用墨绿一色
  • 全 sans 13px 一档正文，serif 只在纸面正文
  • mono 只给时间戳、行×列、耗时等数字
  • 圆角统一 6–7px，不做胶囊不做粗描边
底 面板 导航 状态绿 边线 sans 13px = 一切 · serif = 纸面正文 · mono = 数字

方向三 研究台 · 纸面为心，仪器为壳 中央永远是那张纸，两侧是仪器

明确的混血契约：中央内容区永远是一张带阴影的「稿纸」（纸的语言：衬线、纸色、写线），壳和两侧栏永远是仪器（工具语言：浅灰、卡片、状态点）。两者用一条清晰的纸边分界，纸在桌上——既保住文气，又给足工具感。

  • 壳 = 工具：#f7f6f2 浅灰、卡片、状态点、sans
  • 心 = 纸：中央稿纸带纸边+阴影，衬线正文
  • 输入即写字：输入框是纸上一道写线，不是气泡框
  • 墨绿 = 唯一强调色，只标「活着/进行中」的东西
  • 圆角两档：纸 4px、仪器 8px，绝不混用第三档
台面 仪器 稿纸 活 仪器 sans · 稿纸 serif · mono 数字
